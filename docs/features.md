# XenTerm 功能清单（新 UI 实现规格）

> 本文是 UI 换代（GPUI → Flutter）前的**功能存档**：只记录"产品能做什么"，
> 不记录旧界面的实现。新 UI 必须逐条对照本清单确认覆盖；核心代码位于
> `crates/`（重构后路径），各模块文档是每条功能的实现细节入口。
>
> 标注 🎯 的是 XenTerm 相对 Termius 的**核心优势**，新 UI 中必须保留并有相应的展示位。

## 1. 会话与连接

- **四种会话类型**：SSH、本地 Shell、Telnet、串口，共用同一套标签页模型。
- **内置本地 Shell**：Windows 上自动发现 PowerShell、`cmd.exe`、全部已配置的 WSL
  发行版；其他平台用 `$SHELL`。Windows Shell 默认 UTF-8 启动，WSL 可选发行版与
  启动目录。内置 Shell 是界面的一部分（不可编辑/删除）。
- **SSH 认证**：密码、私钥（文件或内联）、带 passphrase 的私钥、键盘交互式
  2FA/OTP；主机密钥首次确认（SHA-256 指纹）与变更告警。
- **PuTTY PPK v2/v3 私钥**：内存中解密校验（AES-CBC / Argon2 / HMAC），无需 puttygen。
- **多级跳板（ProxyJump）**🎯：按"本机 → 最外层 → … → 目标"排列的跳板链编辑，
  每级独立凭据；兼容旧单跳字段；循环/重复/缺失/非 SSH/超 16 级在联网前报错。
- **出站代理**：SOCKS5（含 `socks5h://`）与 HTTP/HTTPS CONNECT，按会话配置，
  回退读 `ALL_PROXY`；Telnet 同一套逻辑。
- **串口**：波特率、数据位、停止位、校验、流控全可配（serialport）。
- **Telnet**：RFC 854/855 协商（SGA + NAWS 窗口尺寸同步）。
- **触发器（expect/send）**🎯：等待出现→自动应答，可循环、可追加回车，
  用于交互式登录；随会话保存。
- **快速连接**🎯：Ctrl+K 全局唤起，搜索过滤所有已存会话+内置 Shell，回车即连。
- **会话分组**：新建/重命名/删除分组；会话有备注（label）、`last_used` 时间戳。
- **凭据安全**：密码/密钥以 zeroize 的 `Secret` 保存；保存的密码默认掩码，
  "显示"需要本地 GUI 权限位（`allow_secret_reveal`），导入会重置该权限。
- **导入 / 导出**🎯：FinalShell 连接导出（DES/MD5 派生解密）、OpenSSH config
  导入、自有 JSON 导出/导入（见 `docs/config-import.md`）。

## 2. 终端

- **VT/ANSI 完整模拟**（rio-vt）：全屏 TUI（htop/vim/tmux）正常；回滚缓冲 10 万行。
- **鼠标追踪**：SGR/X10 事件转发给请求它的 TUI 程序。
- **DEC 线框字符**：VT100 特殊图形集，UTF-8 模式下可选开启（PuTTY 式开关）。
- **彩色 emoji**🎯：ZWJ/肤色/旗帜按 grapheme 分簇，内嵌 Twemoji PNG 上色。
- **字符编码**：按会话流式解码（UTF-8 默认，GBK 等可选），跨包多字节不乱码。
- **多标签**：重命名、复制标签（同会话第二条连接）、左右移动、拖动排序、
  关闭其他；标签上有连接状态点（拨号中呼吸动画/在线绿/结束灰）。
- **分屏**：可嵌套横向/纵向分屏，拖分隔条调比例，循环切换焦点 pane。
- **回滚内查找**：Ctrl+F 在回滚缓冲中查找；备用屏幕上翻页键交给程序。
- **粘贴保护**：多行粘贴可要求确认；`Ctrl+Alt+V` / `Shift+Insert` 备用粘贴可关。
- **字体/光标**：任意等宽字体+内置字体、字号、行距、粗细、光标样式
  （块/条/下划线）与自定义光标颜色（HSV 选色器）。
- **输出高亮**🎯：日志级别着色（DevOps 预设）+ 自定义正则规则；不破坏原有颜色。
- **静态壁纸**（默认关）🎯：PNG/JPEG/WebP/BMP；覆盖/适应/拉伸/原尺寸/平铺、
  锚点、不透明度、亮度/饱和度/模糊、可读性遮罩、EXIF、旋转翻转裁剪；
  按内容哈希存入配置目录 `wallpapers/`；分屏画布按窗口坐标连续对齐。
  （详细边界见 README 壁纸节；解码防抖串行缓存。）
- **快捷命令**🎯：随会话/全局的常用命令列表，命令栏浮层一键发送；可管理增删改。
- **命令历史**🎯：命令栏输入历史浮层，快速重发。

## 3. 文件

- **SFTP 面板**🎯：跟随终端 `cd` 自动切目录；懒加载目录树；列（名称/大小/时间/权限）。
- **上传/下载**：单文件或整目录树；右键菜单操作；进度进传输列表。
- **批量下载**：所选条目远端打包（tar）后单流传回，完毕清理远端临时文件。
- **内置查看器/编辑器**：小文件文本编辑；只读文件只读打开；外部编辑器保存后自动回传。
- **文件操作**：重命名、删除、新建文件/目录、chmod（保留 setuid/setgid/sticky）。
- **跨会话复制**：把远端文件从会话 A 的 SFTP 复制到会话 B。
- **下载冲突处理**：覆盖或保留两者，每次可选。
- **ZMODEM**：终端内 `sz` 下载到下载目录；`rz` 弹本地选择器经 PTY 上传。
- **WebDAV 同步**：手动上传/下载连接列表；可接受自签名证书；URL/账号/远端路径可配。

## 4. 资源监控 🎯（Termius 没有的核心优势）

- **本机面板**：CPU、内存、交换、网络吞吐、各文件系统用量 + 迷你走势图。
- **远端监控（SSH 通道）**：读远端 `/proc`+`df` 得到同构指标，2 秒刷新；
  会话断开显示掉线状态。
- **远端进程列表**（独立窗口）：按 CPU 排序、复制 PID、结束自己的进程，
  对他人进程发信号前确认。
- **系统信息窗口**：OS/内核/架构/主机名/CPU/内存/文件系统/GPU（#87 GPU 已入面板）。
- 面板可折叠、宽度可拖（180–420px）、停靠边可配。

## 5. 自动化与集成

- **CLI**（`xenterm cli …`）：一次性 SSH 命令、文件列举/读取/传输、会话查询，
  输出人读文本或 `--json`（CI 友好）。
- **MCP 服务**（`xenterm mcp serve`）：把已存会话暴露给 AI 客户端——会话查询、
  远端命令、目录浏览、有界文本读取、上传/下载；每能力独立权限开关，
  凭据永不外传。远程 MCP（HTTP/JWT）见 `docs/REMOTE_MCP.md`。
- **执行日志窗口**：个人执行历史查看。
- **Windows 跳转列表**：最近会话固定到任务栏（新 UI 桌面端可后续恢复）。

## 6. 设置（新 UI 需暴露的全部开关）

主题（深/浅/跟随系统）、面板字体、字号、行距、光标样式与颜色、
粘贴确认、备用粘贴键、回滚查找、emoji、VT100 线框、字符编码（默认）、
输出高亮规则编辑器、壁纸编辑器、快捷面板高度、导航间距（布局类）、
SFTP 面板默认折叠、面板停靠边、WebDAV（开关/URL/账号/密码/远端路径/自签证书）、
MCP/插件权限开关、导入/导出、语言（中英）。

## 7. 界面结构（旧 UI 记录，供新 UI 对照后**替换**）

旧结构：56px 图标导航轨 + 三页（终端/连接/设置）+ 独立窗口（进程监控、
系统信息、执行日志）+ 面板（资源侧栏、SFTP dock、传输、隧道、快捷命令浮层）。
**新 UI 按 `docs/termius/` 规格复刻 Termius**，上述能力重新落位，不再保留旧布局。

## 8. 数据与配置

- 配置目录（`directories` crate 解析）：`sessions` 配置文件 + `wallpapers/`
  内容寻址图片；配置带缓存层，写穿保存失败回滚并出警告横幅。
- 会话字段全集见 `src/config/struct/session.rs`（id/name/host/port/user/auth/
  password/key/proxy/jump链/group/kind/serial参数/encoding/vt100/triggers/
  forwards/local WSL 等）。
- i18n：中英双语（`crate::i18n`），启动语言跟随系统。
- 版本规范：`xt-` 版本号 + `version.sh` 唯一拼接点（`docs/versioning.md`）。

## 9. 平台与打包

- 桌面三平台（Windows MSI/zip、macOS 通用 zip、Linux tar/aarch64），
  AUR/Flatpak 配方在 `packaging/`，WiX 在 `packaging/windows/`（重构后）。
- **新 UI 目标**：桌面三平台 + **iOS/Android**（Flutter 全平台），
  Rust 后端以 FFI/进程形式嵌入。
